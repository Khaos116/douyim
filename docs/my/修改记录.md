### 当前架构图

```text
DouyinModule (Xposed 入口，installSubsystem 逐个装，单点失败隔离)
├── hookActivityLifecycle / hookActivityTouch / hookInstrumentationLifecycle
│     → ImmersiveUi.onActivityResumed/Paused/before|onActivityTouch
├── DoubleTapGuard（FeedComponentGroup.interceptDoubleClick + GestureDetector 监听）
├── ImmersiveTouchGuard（LongPressLayout 手势 + ViewGroup.dispatchTransformedTouchEvent）
├── hookDouyinActivityLifecycle（SplashActivity onCreate/onResume/onStop）
├── FeedContentTracker（BaseListFragmentPanel 构造 + y0(int) 页面选中）
└── PlayerHooks（TTVideoEngine*/SimplifyPlayerImpl/SimVideoUrlModel）
      → PlaybackState（播放状态机）→ ImmersiveUi.onPlaybackChanged/Completed

ImmersiveUi（主循环 + 编排，1529 行）
├── 100ms scan 循环：error → loopBoundary → filter → hide/restore
├── swipeToNext（合成 MotionEvent 上滑，唯一“下一条”实现）
├── checkCurrentFeedContent → filterCurrentItem（3 次确认后 swipe）
├── 暂停恢复界面 + 下载按钮 → VideoDownloader（MP4/MP3）
└── 触摸解析：点击暂停/恢复确认、上滑切视频确认

MainActivity（纯代码 UI）⇄ RemotePreferences "content_filter" ⇄ 抖音进程
```

### 六条数据流

1. currentAweme：`BaseListFragmentPanel` 构造 hook 建 PANELS 注册表 → `current(decor)` 选最优可见 panel（选中优先 + 面积 + 新近度）→ `getCurrentAweme()` → `snapshot()`；每次调用重新计算，无 Aweme 缓存。
2. playback：引擎方法（play/start/resume、pause/stop/release、*completion*、set*Listener）+ 监听回调（onCompletion、onPlaybackStateChanged 0=停止/1=播放/2=暂停/3=错误/4=初始化）→ `PlaybackState`（playing/userPaused/engine 弱引用/候选池/generation）→ `ImmersiveUi` 回调。
3. filter→next：scan 循环 → `checkCurrentFeedContent`（armed 220ms / fallback 900ms，同一 aid+reason 750ms 窗口 3 次确认）→ `filterCurrentItem` → `swipeToNext`（合成上滑：DOWN + 8 步 MOVE + UP，1500ms 防抖 + 运行锁 + 1200ms 看门狗）。
4. completion→next（**已存在**）：`completed()`/loop 边界（position 回绕检测）/error 确认 → `onPlaybackCompleted` → `swipeToNext`。Phase 2 不是从零做，而是加开关 + reason + 单次语义加固。
5. download：`snapshot.playUrls`（play_addr/h264/bytevc1 的 urlList，不带水印链）→ 选择框 → 单线程池 → MP4 走 MediaStore(Q+)/DownloadManager，MP3 走下载源 + `AudioTranscoder`（MediaCodec 解码 → jump3r 编码 128k/192k）→ 全程 `ensureEnabled` 门控 + Toast。
6. preferences：抖音进程 `getRemotePreferences(NAME)` + 设置 App `XposedService.getRemotePreferences(NAME)`；两份缓存（`FeedContentTracker.filterSettings`、`ImmersiveUi` 四个 flag）+ `OnSharedPreferenceChangeListener` 实时刷新。
